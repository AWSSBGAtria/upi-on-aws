Build an extremely high-end, cinematic, immersive 3D web experience for a technical project called:

"UPI on AWS"
Subtitle: "If UPI Were Built Entirely on AWS"

IMPORTANT:
This is NOT a conventional SaaS landing page.
This is NOT a dashboard.
This is NOT a static architecture diagram.

The website should feel like an interactive digital twin of a massive distributed payment infrastructure, presented as a premium technical visualization experience.

The primary goal is to let a visitor physically explore a large-scale 3D representation of a UPI-like payment architecture reimagined using AWS services.

The experience should communicate:
- distributed systems
- payment processing
- cloud architecture
- security
- scalability
- asynchronous communication
- observability
- high availability
- real-time transaction flow

Use the project information below as the source of truth:

CORE PROJECT:
An interactive, animated 3D model visualizing India's UPI as if architected on AWS.

CORE INTERACTIONS:
- Orbit around the architecture
- Zoom deeply into individual components
- Click components to inspect them
- Watch transactions flow through the architecture
- Visualize initiation, authentication, routing, settlement and confirmation
- Map system components to AWS equivalents
- Display cost annotations
- Show high-level topology
- Represent load balancing, auto-scaling, multi-AZ deployment, disaster recovery and encryption layers

ARCHITECTURE LAYERS:
1. Payment Processing
   - AWS Lambda
   - Amazon DynamoDB
   - Amazon SQS

2. Security & Authentication
   - Amazon Cognito
   - AWS KMS
   - AWS WAF
   - Certificate-based 2FA flows

3. API & Routing
   - Amazon API Gateway
   - Amazon Route 53
   - Amazon CloudFront

4. Monitoring & Analytics
   - Amazon CloudWatch
   - AWS X-Ray
   - Amazon QuickSight

TECHNOLOGIES:
- Three.js
- WebGL
- React
- D3.js
- GSAP

--------------------------------------------------
PERFORMANCE
--------------------------------------------------

This is extremely important.

The website must remain highly interactive.

Use:
- Three.js
- WebGL
- instancing where appropriate
- efficient geometry
- GPU-friendly particles
- lazy loading
- level-of-detail techniques
- throttled simulation
- requestAnimationFrame
- adaptive rendering quality

Detect device performance.

If the device is powerful:
Enable maximum visual quality.

If the device is weaker:
Reduce:
- particle count
- shadows
- post-processing
- geometry complexity

But preserve the architecture and interactions.

Provide a "Performance Mode" toggle.
